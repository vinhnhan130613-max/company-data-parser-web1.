# Company Data Parser (Streamlit Web App)

Ứng dụng Python giúp phân tích **dữ liệu thô** của công ty và tự động đưa vào các trường 1–9.

## 🚀 Tính năng
- **Trường 1**: Tên công ty gốc.
- **Trường 2**: Dịch tên công ty sang tiếng Anh (ProperName + Industry + CompanyType).
- **Trường 3**: Đường từ địa chỉ thuế.
- **Trường 4**: Dịch đường sang tiếng Anh.
- **Trường 5**: Phường từ địa chỉ thuế.
- **Trường 6**: Dịch phường sang tiếng Anh.
- **Trường 7**: Điện thoại.
- **Trường 8**: Người đại diện (chuẩn hóa viết hoa).
- **Trường 9**: Tóm tắt ngày/tháng/năm + phone + xác nhận.
