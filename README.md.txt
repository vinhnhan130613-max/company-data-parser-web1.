# Company Data Parser (Streamlit Web App)

Ứng dụng Python giúp xử lý dữ liệu thô của công ty theo các quy tắc chuẩn hóa, dịch sang tiếng Anh, và chuẩn hóa địa chỉ.  
Triển khai dưới dạng web app bằng **Streamlit**.

## 🚀 Tính năng
- Chuẩn hóa tên công ty (Trường 1).
- Dịch tên công ty sang tiếng Anh theo quy tắc ProperName + Industry + CompanyType (Trường 2).
- Chuẩn hóa và dịch địa chỉ (Trường 3–6).
- Lấy số điện thoại (Trường 7).
- Chuẩn hóa tên người đại diện (Trường 8).
- Tự động hiển thị thông tin ngày/tháng/năm + phone + xác nhận (Trường 9).
